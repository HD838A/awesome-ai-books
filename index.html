关于这些框架

open-multi-agent — TypeScript 生态最缺的多代理协作框架。把 Claude Code 最核心的多代理编排系统从零重写，只用 3 个依赖、27 个文件，就实现了大目标自动拆解、带依赖的并行调度、消息总线与共享内存协作。一行代码搞定复杂任务，填补了 JS/TS 轻量多代理框架的核心空白。支持 Claude、GPT、Grok、Ollama 等任意模型，全程单进程运行。

gstack — 亮点是 YC 的知识和评判标准，适合产品和 idea 的深度打磨，AI 会对你进行灵魂拷问。未来版本支持知识沉淀，适合大工程的架构设计阶段。

superpower — 强调流程纪律：spec → plan → 拆解 → 执行 → 测试 review → 提交。流程控制好，适合进入执行阶段时的任务推进。

大工程用 gstack 做产品和 idea 打磨，superpower 来执行。
