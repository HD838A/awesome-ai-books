1.1 OpenClaw 是什么

💡 类比：如果把 iOS 系统看作一个"让 App 在用户设备上运行"的框架，那么 OpenClaw 就是一个"让 AI Agent 在用户设备上运行"的框架。两者都强调本地运行和用户控制。

1.1.1 项目定位

OpenClaw is a personal AI assistant that runs on your own devices.

1.1.2 核心设计理念

  1. "AI that actually does things"：不仅是对话，还要能执行实际操作
  2. TypeScript 优先：选择 TypeScript 是为了最大化 hackability
  3. 插件化架构：像 iOS 的 Target Extension 一样
  4. 安全隔离：通过沙箱机制确保代码执行安全

1.2 TypeScript 速查

类型注解

// Swift
let name: String = "OpenClaw"
let count: Int = 42
// TypeScript
const name: string = "OpenClaw";
const count: number = 42; // 没有 Int，统一用 number

接口与类型别名

// Swift
protocol Agent {
    var id: String { get }
    func run(message: String) async -> String
}
// TypeScript
interface Agent {
    id: string;
    run(message: string): Promise<string>;
}

iOS 开发者视角总结

如果你熟悉 iOS 开发，那么可以把 OpenClaw 看作是一个"AI App 开发框架"。它的 Agent 类似于你的 AppDelegate，负责应用的生命周期管理；Plugin 类似于 App Extension，允许你扩展核心功能；Gateway 类似于 Network.framework，处理所有网络通信。
