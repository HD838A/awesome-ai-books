第 6 章 · Skills 系统与插件架构

概述

本章深入探讨 OpenClaw 的 Skills 系统。Skills 是 OpenClaw 提供的可复用功能模块。

6.1 Skills 与 Plugin

💡 类比：这类似于 iOS 的 App Extensions 和 Shortcuts 的区别。App Extension 是系统级扩展，Shortcuts 是用户级技能。

概念层级类比
Plugin系统级App Extension
Skill用户级Shortcut

6.2 本章小结

Skills 系统和插件架构是 OpenClaw 可扩展性的核心。Plugin 提供系统级扩展能力，Skill 提供用户级可复用功能。
