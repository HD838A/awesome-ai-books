第 4 章 · Agent 生命周期管理

概述

本章深入探讨 OpenClaw 的 Agent 生命周期管理。Agent 是 OpenClaw 的核心概念，代表一个可以执行任务的 AI 实体。

4.1 Agent 生命周期

创建 → 初始化 → 运行 → 暂停 → 终止
  │        │        │       │       │
  ▼        ▼        ▼       ▼       ▼
  New   Init    Running  Paused  Terminated

4.3 本章小结

Agent 生命周期管理是 OpenClaw 的核心功能之一，类似于 iOS App 的生命周期管理。通过理解 New → Init → Running → Paused → Terminated 的状态转换，开发者可以更好地控制 Agent 的行为。
