## 关于这些框架

每本书解读一个开源 AI 框架，它们的设计思想和使用场景各有侧重：

**Open Multi-Agent 实战** — TypeScript 生态最缺的多代理协作框架。把 Claude Code 最核心的多代理编排系统从零重写，只用 3 个依赖、27 个文件，就实现了大目标自动拆解、带依赖的并行调度、消息总线与共享内存协作。一行代码搞定复杂任务，填补了 JS/TS 轻量多代理框架的核心空白。支持 Claude、GPT、Grok、Ollama 等任意模型，全程单进程运行。

**OpenClaw 源码解析** — 运行在本地设备的 AI 助手平台，通过模块化架构连接各类 AI 模型与服务，提供任务自动化、长程记忆、Web 可视化等核心能力。Agent 生命周期管理、Tools 系统、Skills 生态、Gateway 通信层、安全机制、记忆系统、Plugin 架构等核心模块的完整源码解读。

**gstack 源码解读** — 亮点是 YC 的知识和评判标准，适合产品和 idea 的深度打磨，AI 会对你进行灵魂拷问。未来版本支持知识沉淀，适合大工程的架构设计阶段。

**Superpowers 源码解析** — 强调流程纪律：spec → plan → 拆解 → 执行 → 测试 review → 提交。流程控制好，适合进入执行阶段时的任务推进。

> 大工程用 gstack 做产品和 idea 打磨，superpower 来执行。
