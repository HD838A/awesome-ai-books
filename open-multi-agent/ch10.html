第 10 章：可观测性

为什么你的 Agent 系统需要"仪表盘"

想象你开一辆车，却没有仪表盘——没有速度表、没有油量表、没有发动机故障灯。这辆车也许能开，但出了问题你完全不知道。

Open Multi-Agent 的可观测性系统就是你的"仪表盘"。它让你：

  • 看见每个 Agent 在做什么
  • 量化Token 消耗和成本
  • 追踪问题出在哪一步
  • 监控系统健康状态

10.1 追踪系统详解

10.1.1 TraceEvent 结构

位置：src/utils/trace.ts + src/types.ts

框架在每个关键节点发射追踪事件：

interface TraceEvent {
  type: 'llm_call' | 'tool_call' | 'task' | 'agent'
  runId: string          // 关联同一次运行的唯一 ID
  agent: string          // Agent 名称
  model: string          // 使用的模型
  turn?: number          // 对话轮次
  tokens?: {
    input_tokens: number
    output_tokens: number
  }
  tool?: string          // 工具名称（tool_call 类型）
  taskTitle?: string     // 任务标题（task 类型）
  success?: boolean      // 是否成功
  retries?: number       // 重试次数
  startMs: number        // 开始时间
  endMs: number          // 结束时间
  durationMs: number     // 持续时间（毫秒）
}

10.1.2 安全设计

追踪系统的一个关键设计原则：可观测性永远不能破坏执行。

export function emitTrace(
  fn: ((event: TraceEvent) => void | Promise<void>) | undefined,
  event: TraceEvent,
): void {
  if (!fn) return
  try {
    const result = fn(event) as unknown
    if (result && typeof (result as Promise<unknown>).catch === 'function') {
      (result as Promise<unknown>).catch(noop)  // 吞掉异步 reject
    }
  } catch {
    // 吞掉所有错误 — 追踪出错不影响主流程
  }
}

为什么要这样做？

如果追踪服务崩溃（如发送到远程服务器失败），框架不应该因此停止运行。用户的业务逻辑优先级高于可观测性。

10.1.3 追踪处理器

function handleTrace(event: TraceEvent): void {
  const dur = `${event.durationMs}ms`.padStart(7)

  switch (event.type) {
    case 'llm_call':
      console.log(
        `[LLM]  ${dur} agent=${event.agent} model=${event.model}` +
        ` turn=${event.turn} tokens=${event.tokens.input_tokens}in/${event.tokens.output_tokens}out`
      )
      break

    case 'tool_call':
      console.log(
        `[TOOL] ${dur} agent=${event.agent} tool=${event.tool}` +
        ` error=${event.isError}`
      )
      break

    case 'task':
      console.log(
        `[TASK] ${dur} task="${event.taskTitle}" agent=${event.agent}` +
        ` success=${event.success} retries=${event.retries}`
      )
      break

    case 'agent':
      console.log(
        `[AGNT] ${dur} agent=${event.agent} turns=${event.turns}` +
        ` tools=${event.toolCalls}`
      )
      break
  }
}

10.1.4 集成追踪

const orchestrator = new OpenMultiAgent({
  defaultModel: 'claude-sonnet-4-6',
  onTrace: handleTrace,  // 注册追踪处理器
})

10.2 OrchestratorEvent 事件系统

10.2.1 事件类型

type OrchestratorEvent = {
  type: 'agent_start'       // Agent 开始执行
            | 'agent_complete'   // Agent 完成
            | 'task_start'        // 任务开始
            | 'task_complete'     // 任务完成
            | 'task_skipped'      // 任务跳过
            | 'task_retry'        // 任务重试
            | 'message'           // 消息事件
            | 'error'             // 错误事件
  agent?: string
  task?: string
  data?: unknown
}

10.2.2 进度处理器

const startTimes = new Map<string, number>()

function handleProgress(event: OrchestratorEvent): void {
  const ts = new Date().toISOString().slice(11, 23)

  switch (event.type) {
    case 'agent_start':
      startTimes.set(event.agent ?? '', Date.now())
      console.log(`[${ts}] AGENT START  → ${event.agent}`)
      break

    case 'agent_complete': {
      const elapsed = Date.now() - (startTimes.get(event.agent ?? '') ?? Date.now())
      console.log(`[${ts}] AGENT DONE   ← ${event.agent} (${elapsed}ms)`)
      break
    }

    case 'task_start':
      console.log(`[${ts}] TASK START   ↓ ${event.task}`)
      break

    case 'task_complete':
      console.log(`[${ts}] TASK DONE    ✓ ${event.task}`)
      break

    case 'task_retry': {
      const d = event.data as {
        attempt: number
        maxAttempts: number
        error: string
        nextDelayMs: number
      }
      console.log(`[${ts}] TASK RETRY  ⚡ ${event.task} — ${d.attempt}/${d.maxAttempts}`)
      break
    }
  }
}

const orchestrator = new OpenMultiAgent({
  defaultModel: 'claude-sonnet-4-6',
  onProgress: handleProgress,
})

10.3 成本追踪

10.3.1 Token 统计

let totalInputTokens = 0
let totalOutputTokens = 0
let llmCallCount = 0

orchestrator.onTrace = (event) => {
  if (event.type === 'llm_call') {
    totalInputTokens += event.tokens?.input_tokens ?? 0
    totalOutputTokens += event.tokens?.output_tokens ?? 0
    llmCallCount++
  }
}

10.3.2 成本计算

const PRICING = {
  'claude-sonnet-4-6': { input: 3, output: 15 },      // $/MTok
  'claude-opus-4-7':    { input: 15, output: 75 },
  'gpt-4o':             { input: 5, output: 15 },
  'gpt-4o-mini':        { input: 0.15, output: 0.6 },
}

function calculateCost(events: TraceEvent[]): CostReport {
  const byModel = new Map<string, { input: number; output: number; calls: number }>()

  for (const event of events) {
    if (event.type !== 'llm_call') continue

    const pricing = PRICING[event.model]
    if (!pricing) continue

    const existing = byModel.get(event.model) ?? { input: 0, output: 0, calls: 0 }
    existing.input += event.tokens?.input_tokens ?? 0
    existing.output += event.tokens?.output_tokens ?? 0
    existing.calls++
    byModel.set(event.model, existing)
  }

  const lines: string[] = ['📊 成本报告', '══════════════════════════════']
  let totalCost = 0

  for (const [model, usage] of byModel) {
    const pricing = PRICING[model]
    const inputCost = (usage.input / 1_000_000) * pricing.input
    const outputCost = (usage.output / 1_000_000) * pricing.output
    const modelCost = inputCost + outputCost
    totalCost += modelCost

    lines.push(`${model}`)
    lines.push(`  调用 ${usage.calls} 次`)
    lines.push(`  输入 ${usage.input.toLocaleString()} tokens ($${inputCost.toFixed(4)})`)
    lines.push(`  输出 ${usage.output.toLocaleString()} tokens ($${outputCost.toFixed(4)})`)
    lines.push(`  小计 $${modelCost.toFixed(4)}`)
  }

  lines.push('══════════════════════════════')
  lines.push(`💰 总成本: $${totalCost.toFixed(4)}`)
  lines.push(`🔢 LLM 调用: ${llmCallCount} 次`)
  lines.push(`📝 Token 总量: ${totalInputTokens.toLocaleString()} in / ${totalOutputTokens.toLocaleString()} out`)

  return { totalCost, byModel, lines: lines.join('\n') }
}

10.4 审批门（Approval Gate）

10.4.1 什么是审批门？

高级特性：在每批任务完成后、下一批开始前，可以选择批准或拒绝。

const orchestrator = new OpenMultiAgent({
  defaultModel: 'claude-sonnet-4-6',
  onApproval: async (completedTasks, pendingTasks) => {
    console.log(`\n${completedTasks.length} 个任务完成，${pendingTasks.length} 个待执行`)

    // 显示完成的任务结果
    for (const task of completedTasks) {
      console.log(`  ✓ ${task.title}: ${task.result?.success ? '成功' : '失败'}`)
    }

    // 交互式审批（示例）
    const answer = await askUser('是否继续执行剩余任务？(y/n)')
    return answer.toLowerCase() === 'y'
  },
})

10.4.2 触发条件

审批门不会在以下情况触发：

  • 本批所有任务都失败（无可审批内容）
  • 没有剩余待执行任务（最终批次）

10.5 OpenTelemetry 集成

10.5.1 为什么用 OpenTelemetry？

OpenTelemetry（OTel）是云原生计算基金会（CNCF）的可观测性标准，支持：

  • 分布式追踪（Traces）
  • 指标（Metrics）
  • 日志（Logs）

10.5.2 集成示例

import { NodeTracerProvider } from '@opentelemetry/sdk-trace-node'
import { ConsoleSpanExporter, SimpleSpanProcessor } from '@opentelemetry/sdk-trace-node'
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http'

// 设置追踪提供者
const provider = new NodeTracerProvider()
provider.addSpanProcessor(new SimpleSpanProcessor(new ConsoleSpanExporter()))

// 可选：发送到 OTEL 收集器
// provider.addSpanProcessor(new SimpleSpanProcessor(
//   new OTLPTraceExporter({ url: 'http://localhost:4318/v1/traces' })
// ))
provider.register()

// 转换为 OTLP 格式
orchestrator.onTrace = (event) => {
  const span = tracer.startSpan(`agent.${event.type}`)
  span.setAttributes({
    'agent.name': event.agent,
    'agent.model': event.model,
    'agent.run_id': event.runId,
    'agent.duration_ms': event.durationMs,
  })

  if (event.type === 'llm_call') {
    span.setAttributes({
      'llm.tokens.in': event.tokens.input_tokens,
      'llm.tokens.out': event.tokens.output_tokens,
      'llm.turn': event.turn ?? 0,
    })
  }

  if (event.type === 'tool_call') {
    span.setAttributes({ 'tool.name': event.tool ?? '' })
  }

  span.end()
}

10.6.1 环境区分

const isDevelopment = process.env.NODE_ENV === 'development'

const orchestrator = new OpenMultiAgent({
  defaultModel: 'claude-sonnet-4-6',

10.6.2 采样策略

高频场景下，不要记录所有事件：

let eventCount = 0
const sampleRate = 0.1  // 采样 10%

orchestrator.onTrace = (event) => {
  eventCount++
  if (event.type === 'llm_call' && Math.random() > sampleRate) {
    return  // 跳过大部分 LLM 调用
  }
  sendToCollector(event)
}

10.6.3 异步缓冲

const buffer: TraceEvent[] = []
const FLUSH_INTERVAL = 5000

setInterval(async () => {
  if (buffer.length === 0) return
  const batch = buffer.splice(0, buffer.length)
  await collector.send(batch)  // 批量发送
}, FLUSH_INTERVAL)

orchestrator.onTrace = (event) => {
  buffer.push(event)
}

10.7.2 性能瓶颈定位

const durations = new Map<string, number[]>()

orchestrator.onTrace = (event) => {
  if (event.type === 'llm_call' || event.type === 'tool_call') {
    const key = `${event.type}:${event.agent}:${event.tool ?? event.model}`
    const existing = durations.get(key) ?? []
    existing.push(event.durationMs)
    durations.set(key, existing)
  }
}

// 运行结束后分析
process.on('exit', () => {
  for (const [key, times] of durations) {
    const avg = times.reduce((a, b) => a + b, 0) / times.length
    console.log(`${key}: avg=${avg.toFixed(0)}ms, count=${times.length}`)
  }
})

本章小结

  1. TraceEvent：四种类型（llm_call/tool_call/task/agent），包含时间戳、Token 消耗等详细信息。
  1. emitTrace 安全设计：try-catch 包裹，异步回调的 reject 被吞掉，确保可观测性不影响主流程。
  1. OrchestratorEvent：任务/Agent 生命周期事件，包括重试事件 task_retry。
  1. 成本追踪：基于 Token 用量和模型定价计算成本。
  1. 审批门（onApproval）：批次完成后可选择批准或拒绝执行。
  1. OpenTelemetry 集成：将 TraceEvent 转换为 OTLP 格式，支持分布式追踪。
