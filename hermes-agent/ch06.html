本章目标



学完这章，你将能够：

6.1 什么是 Skill？



6.1.1 类比：技能 vs 工具



想象一个专业的厨师团队：

概念类比说明

Tool厨师的刀、锅、炉灶单一功能，执行具体操作
Skill厨师的"川菜"技能一套完整的工作流程和方法论
Plugin厨房设备（如蒸柜、烤箱）提供额外能力的模块

工具（Tool）     →   "切菜"

                  "调味"

                  "掌火"



技能（Skill）    →   "川菜烹饪"  ← 包含：

                     - 何时用刀

                     - 如何调味

                     - 火候控制

                     - 摆盘要求



插件（Plugin）   →   添加一台蒸柜

                     → 让厨师能做"粤菜蒸菜"


6.1.2 Skill 的本质



Skill 是一套结构化的提示词（Structured Prompt），它告诉 Agent：

  • 做什么 — 任务目标
  • 怎么做 — 工作流程
  • 用什么工具 — 工具选择
  • 输出什么格式 — 结果规范


💡 关键洞察：Skill 不是代码，而是给 AI 的工作指南。它通过自然语言指导 Agent 如何完成特定类型的任务。

6.2.2 Frontmatter 字段



字段类型必需说明

namestring✅Skill 名称（唯一标识）
descriptionstring✅简短描述，Agent 用它决定何时调用
versionstring✅语义版本号
metadata.hermes.tagsarray❌分类标签
metadata.hermes.related_skillsarray❌关联的其他 Skill

6.2.3 章节说明



章节用途重要性

Overview任务的高层概述✅ 必须
Prerequisites前置条件（工具、环境）✅ 必须
Inputs用户需要提供的输入推荐
Workflow详细的工作流程✅ 必须
Tools Reference工具使用参考推荐
Tips最佳实践和注意事项可选



6.3 实战：解读 dogfood Skill



6.3.1 任务概述



dogfood 是一个系统化 Web 应用 QA 测试的 Skill。它指导 Agent：

  • 规划测试范围
  • 探索每个页面
  • 收集证据（截图、错误日志）
  • 分类和排序问题
  • 生成结构化报告


6.3.2 Workflow 解析



## Workflow



Follow this 5-phase systematic workflow:




Phase 1: Plan



  • Create the output directory structure
  • Identify the testing scope
  • Build a rough sitemap





Phase 2: Explore


For each page or feature:


  • Navigate to the page
  • Take a snapshot
  • Check the console
  • Take an annotated screenshot
  • Test interactive elements





Phase 3: Collect Evidence


...




Phase 4: Categorize


...




Phase 5: Report


...


为什么分 5 个 Phase？

Phase 1: Plan      → 磨刀不误砍柴工

Phase 2: Explore   → 系统化探索

Phase 3: Collect   → 捕获证据

Phase 4: Categorize→ 整理归类

Phase 5: Report    → 输出成果

6.5 Skill 的安全机制



6.5.1 安全扫描



Agent 创建的 Skill 会经过安全扫描：

# skill_manager_tool.py

from tools.skills_guard import scan_skill



def _security_scan_skill(skill_dir):

    result = scan_skill(skill_dir, source="agent-created")

    allowed, reason = should_allow_install(result)

    

    if allowed is False:

        return f"Security scan blocked: {reason}"

    

    return None  # 通过


6.5.2 扫描检查项



检查项说明风险

恶意 URL检测可疑的外部链接数据外泄
可疑代码检测隐藏的可执行代码命令注入
权限提升检测提权意图安全绕过
路径遍历检测文件路径操作文件系统攻击

6.5.3 命名规范



Skill 名称必须符合以下规则：

^[a-z0-9][a-z0-9._-]*$


合法名称非法名称原因

dogfoodDogfood必须小写
code-reviewcode review不能有空格
my.skillmy..skill不能连续点
a1-b21-a必须以字母或数字开头



6.6 编写高质量 Skill 的技巧



6.6.1 描述要清晰



❌ 差的描述：

description: "研究"


✅ 好的描述：

description: "深度研究某个主题，包括竞品分析、

技术调研、市场趋势等，输出结构化研究报告"


6.6.2 Workflow 要具体



❌ 模糊的步骤：

### Phase 1: 研究


  • 搜索相关信息
  • 分析
  • 输出


✅ 具体的步骤：

### Phase 1: 信息收集


  • 使用 web_search 搜索主题关键词
  • 使用 web_extract 获取前 5 个结果详情
  • 记录关键发现到笔记
  • 如果发现新关键词，重复搜索


6.6.3 提供工具参考



## Tools Reference




browser_vision



  • 用途：截图 + AI 分析
  • annotate=true：在截图上标注交互元素
  • 使用场景：理解页面布局、识别问题





browser_console



  • 用途：获取 JavaScript 控制台错误
  • 关键：在导航后和重要交互后都要检查
  • 使用场景：发现 JS 运行时错误


6.6.4 添加边界条件



## Tips




  • URL 无效时：返回友好错误，说明需要有效 URL
  • 页面加载超时时：等待 5 秒重试，最多 3 次
  • 截图失败时：跳过该页，记录到报告中
  • 控制台无错误时：在报告中注明"无控制台错误"

维度SkillPluginTool

6.7.1 选择指南



我需要...

│

├─ 执行一个具体操作          → Tool

│   例：搜索网页、读文件

│

├─ 提供系统级能力            → Plugin

│   例：记忆管理、浏览器控制

│

└─ 指导 Agent 完成复杂任务   → Skill

    例：QA 测试、代码审查、研究报告

⭐ 重点回顾



  • Skill 是一套结构化的提示词，指导 Agent 完成特定类型的任务
  • SKILL.md 格式包含 Frontmatter（名称、描述、版本）和 Workflow（工作流程）
  • Skill 通过 skill_manager 工具管理，支持创建、编辑、补丁、删除
  • Agent 创建的 Skill 会经过安全扫描，防止恶意代码
  • Skill 与 Plugin、Tool 有本质区别：Tool 做具体操作，Plugin 提供系统能力，Skill 指导工作流程
