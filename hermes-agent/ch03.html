3.1 名词解释：什么是 Function Calling？



在开始之前，让我们先把几个容易混淆的概念理清楚。

3.1.1 Function Calling vs Tool Use



术语全称说明

Function Calling函数调用AI 模型主动"调用"一个预定义函数的能力
Tool Use工具使用更通用的概念，包括 Function Calling 和其他工具交互方式
Tool Calling工具调用Function Calling 在某些 API（如 Anthropic）中的叫法

💡 提示：虽然名字不同，但它们本质上说的是同一件事——让 AI 模型能够"动手做事"，而不是只"动嘴说话"。



3.1.2 为什么需要 Function Calling？



想象一下，你问 AI：

你：帮我查一下北京今天的天气



没有 Function Calling 的 AI 只能：

"根据我的知识，北京今天的天气是晴朗的，气温约 25°C。"


有 Function Calling 的 AI 能：

1. 调用 web_search 工具 → 实时获取天气数据


  • 调用完成后 → 返回准确的实际天气信息


⚠️ 注意：没有 Function Calling 的 AI 只能回答"截至我训练日期的知识"。有了 Function Calling，AI 才能获取实时信息、执行真实操作。





3.2 工具注册与发现机制



Hermes Agent 使用注册表模式（Registry Pattern）来管理所有工具。

3.2.1 中心化注册表



# tools/registry.py - 工具注册表

class ToolRegistry:

    """工具注册表（简化版）"""

    

    def __init__(self):

        self._tools: Dict[str, ToolEntry] = {}

    

    def register(

        self,

        name: str,           # 工具名称，如 "web_search"

        toolset: str,         # 所属工具集，如 "web_tools"

        schema: dict,         # 工具参数模式（JSON Schema）

        handler: Callable,    # 实际执行的函数

        check_fn: Callable,  # 可用性检查函数

    ):

        self._tools[name] = ToolEntry(...)


3.2.2 工具的自我注册



每个工具文件在模块加载时自动注册：

# tools/web_tools.py




定义工具的处理函数


def web_search(query: str, limit: int = 5) -> str:

    """搜索网页"""

    ...




在模块加载时注册


from tools.registry import registry



registry.register(

    name="web_search",

    toolset="web_tools",

    schema={

        "name": "web_search",

        "description": "Search the web for information...",

        "parameters": {

            "type": "object",

            "properties": {

                "query": {"type": "string", "description": "..."},

                "limit": {"type": "integer", "description": "..."}

            },

            "required": ["query"]

        }

    },

    handler=web_search,  # 绑定处理函数

    check_fn=lambda: bool(os.getenv("EXA_API_KEY")),  # 检查是否可用

)

3.3 函数调用（Function Calling）流程



当用户发送消息后，工具调用的完整流程如下：

3.3.1 流程概览



用户: "帮我搜索 Python 最新动态"



────────────────────────────────────────────────────────────



【步骤 1】组装请求



{

    "model": "claude-sonnet-4",

    "messages": [

        {"role": "user", "content": "帮我搜索 Python 最新动态"}

    ],

    "tools": [web_search_schema, read_file_schema, ...]  # 所有可用工具

}



────────────────────────────────────────────────────────────



【步骤 2】AI 模型决策



模型判断：需要调用 web_search 工具



{

    "role": "assistant",

    "content": null,

    "tool_calls": [

        {

            "id": "call_123",

            "function": {

                "name": "web_search",

                "arguments": "{\"query\": \"Python 最新动态 2024\"}"

            }

        }

    ]

}



────────────────────────────────────────────────────────────



【步骤 3】执行工具



tool_result = registry.dispatch("web_search", {"query": "Python 最新动态 2024"})



{

    "role": "tool",

    "tool_call_id": "call_123",

    "content": "1. Python 3.13 发布...\n2. PEP 749 提议..."

}



────────────────────────────────────────────────────────────



【步骤 4】循环或结束



继续循环：把工具结果发回给模型，看是否还需要其他工具

或

结束：返回最终文本响应给用户


3.3.2 核心代码解析



# model_tools.py - 工具调度器

def handle_function_call(function_name, function_args, task_id, user_task):

    """执行单个工具调用"""

    

    # 1. 解析参数（处理模型可能返回的类型错误）

    args = coerce_tool_args(function_name, json.loads(function_args))

    

    # 2. 从注册表获取处理函数并执行

    result = registry.dispatch(function_name, args, task_id=task_id)

    

    return result




3.4 工具集（Toolset）的组织与管理



3.4.1 什么是 Toolset？



Toolset 是一组相关工具的集合。Hermes Agent 按功能把工具分组：

Toolset包含工具说明

web_toolsweb_search, web_extract网页搜索和内容提取
terminal_toolsterminal在终端执行命令
file_toolsread_file, write_file, patch, search_files文件操作
browser_toolsbrowser_navigate, browser_click, ...浏览器自动化
skills_toolsskills_list, skill_view, skill_manageSkill 管理

3.4.2 启用/禁用工具集



# 只启用特定工具集

agent = AIAgent(

    enabled_toolsets=["web_tools", "file_tools"]

)




或禁用某些工具集


agent = AIAgent(

    disabled_toolsets=["browser_tools"]  # 禁用浏览器工具

)


3.4.3 工具的可用性检查



每个工具可以定义一个 check_fn，用于检查环境是否满足要求：

# 示例：web_search 工具的可用性检查

registry.register(

    name="web_search",

    toolset="web_tools",

    schema=...,

    handler=web_search,

    check_fn=lambda: bool(os.getenv("EXA_API_KEY") or 

                         os.getenv("FIRECRAWL_API_KEY"))

)




3.5 内置工具一览



Hermes Agent 内置了丰富的工具。下面介绍最核心的几个。

3.5.1 Web 搜索工具



工具名：web_search

作用：在互联网上搜索信息

使用场景：

  • 查询实时新闻和价格
  • 搜索技术文档
  • 查找产品信息


# 使用示例

result = web_search(

    query="Python 异步编程 best practices",

    limit=5  # 返回 5 条结果

)


3.5.2 文件操作工具



Hermes Agent 提供了四个核心文件操作工具：

工具作用示例

read_file读取文件内容read_file(path="config.yaml")
write_file写入或覆盖文件write_file(path="hello.py", content="...")
patch智能修改文件对文件进行精确的行级修改
search_files搜索文件内容搜索包含关键词的文件

💡 提示：patch 是最常用的文件修改工具，它支持：

  • 按行号精确修改
  • 插入新内容
  • 删除指定行
  • 替换匹配内容


# patch 示例

result = patch(

    path="app.py",

    operations=[

        {"op": "replace", "old": "x = 1", "new": "x = 2"},

        {"op": "insert", "after": "def main():", "new": "    logger.info('started')"}

    ]

)


3.5.3 终端执行工具



工具名：terminal

作用：在本地终端执行命令

# 执行命令

result = terminal(

    command="pip install requests",

    timeout=60  # 超时时间（秒）

)


⚠️ 注意：终端工具有风险！Hermes Agent 会检测潜在的破坏性命令（如 rm -rf /），但使用时请谨慎。

3.6 工具调用的小技巧



3.6.1 工具并行执行



Hermes Agent 支持并行执行独立的工具调用：

# 以下两个调用可以并行执行

tool_calls = [

    {"name": "read_file", "args": {"path": "a.txt"}},

    {"name": "read_file", "args": {"path": "b.txt"}},

]


结果几乎同时返回


💡 提示：只要工具之间没有依赖关系（不读写同一文件），Hermes 就会自动并行执行，减少等待时间。



3.6.2 工具结果大小限制



为了防止工具返回过多内容导致上下文溢出，工具结果有大小限制：

工具默认限制可配置

web_search10,000 字符否
read_file50,000 字符否
terminal5,000 字符是



⭐ 重点回顾



  • Function Calling 让 AI 模型能够调用外部工具，获取实时信息或执行真实操作
  • 工具注册表模式：每个工具通过 registry.register() 自我注册
  • 工具集（Toolset）：按功能分组工具，支持批量启用/禁用
  • 工具调用流程：组装请求 → AI 决策 → 执行工具 → 返回结果 → 循环或结束
  • 核心内置工具：web_search、read_file/write_file、terminal、browser_tools
