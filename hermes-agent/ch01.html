1.1 从 AI 模型到 Agent：发生了什么变化？



你有没有过这种体验：对着一个 AI 对话，问它"帮我查一下天气"，它给你一段关于天气的描述——然后呢？它不会真的去查天气。

这就是 AI 模型 的局限：它只会"说"，不会"做"。

而 Agent（发音：/'eɪdʒənt/，英文意思是"代理人"）不一样。想象一个贴心的私人助理：

你说："帮我订一张下周三去上海的机票。"


>

助理会：


1. 打开订票网站


2. 搜索航班


3. 比较价格和时间


4. 选好机票


5. 填写你的信息


6. 完成支付


>

然后告诉你："搞定！机票已出票。"



这个助理不是在"描述"订票过程，而是真的在执行。Agent 就像这样一个能"动手做事"的 AI。

Agent 的三大超能力



一个完整的 Agent，通常具备这三种能力：

能力说明类比

工具调用能使用外部工具（查资料、执行代码、操作文件）助理的手
记忆能记住之前的对话内容，下次继续助理的笔记本
规划能把复杂任务拆解成多个步骤助理的脑袋

Hermes Agent 同时具备这三种能力，而且还有额外惊喜：多 Agent 协作和Skill 扩展机制。



1.2 Hermes Agent 是什么？



Hermes Agent 是 Nous Research 开发的一个开源 Agent 框架。它的定位很明确：

"Build agents with a built-in learning loop."（构建具有内置学习循环的 Agent。）



翻译成人话就是：Hermes Agent 不只是一个"听话的助理"，它还是一个能从经验中学习的助理。

核心特性一览



特性说明详细章节

Hermes Agent 的设计理念



Hermes Agent 有几个独特的设计哲学：

  • 插件化架构：Memory 系统是可插拔的，你可以用自带的简单记忆，也可以接入 Mem0、Holographic 等高级记忆系统。


  • 配置文件驱动：Agent 的身份、工具、记忆都通过文件定义，而不是硬编码。这让 Agent 更容易定制和分享。


  • 即学即用：Skill 机制让你可以通过写一份 Markdown 文件来给 Agent 添加新技能，就像给员工发一份培训手册。




1.3 ⭐ 5 分钟 Hello World：运行你的第一个 Agent



废话少说，让我们直接跑起来！

1.3.1 环境要求



在开始之前，确保你的电脑满足以下条件：

  • Python: 3.11 或更高版本
  • pip: Python 包管理器（通常随 Python 一起安装）
  • API Key: Claude 或 OpenAI 的 API 密钥


💡 提示：推荐使用 Claude 的 API，效果更好。如果没有，官网 可以申请。

1.3.2 安装 Hermes Agent



打开终端（Windows 用户用 PowerShell 或 CMD），运行以下命令：

pip install hermes-agent


安装完成后，验证一下：

hermes --version


如果看到版本号（比如 0.8.0），说明安装成功！

1.3.3 配置 API 密钥



Hermes Agent 需要调用 AI 模型，所以需要配置 API 密钥。

方法一：环境变量

# macOS / Linux

export ANTHROPIC_API_KEY="sk-ant-xxxxxx"




Windows PowerShell


$env:ANTHROPIC_API_KEY="sk-ant-xxxxxx"


方法二：.env 文件

在项目根目录创建 .env 文件：

# .env

ANTHROPIC_API_KEY=sk-ant-xxxxxx


⚠️ 注意：API 密钥不要泄露给他人，也不要提交到 GitHub！.env 文件应该加入 .gitignore。

1.3.4 运行你的第一个 Agent



创建一个新文件 hello_agent.py：

# hello_agent.py

from run_agent import AIAgent



agent = AIAgent()

response = agent.run_conversation("你好！请介绍一下你自己。")

print(response)


然后运行：

python hello_agent.py


预期输出：

你好！我是 Hermes Agent，一个能帮助你完成各种任务的 AI 助手。

我可以：


  • 回答问题和提供信息
  • 帮你写代码和分析代码
  • 搜索和分析文档
  • 还有很多其他能力...


🎉 恭喜你完成了第一个 Agent 的运行！

1.3.5 稍完整的例子：带记忆的对话



上一个例子每次运行都是全新的 Agent，不会"记住"之前的对话。让我们试试带记忆的版本：

# hello_memory.py

from run_agent import AIAgent

from plugins.memory.honcho.session import SessionManager



session_manager = SessionManager()

session = session_manager.create_session(user_id="hello_world")



agent = AIAgent(session_manager=session_manager)




第一轮对话


response1 = agent.run_conversation("我叫小明，请记住我的名字。", session_id=session.id)

print(f"Agent: {response1}")




第二轮对话


response2 = agent.run_conversation("我叫什么名字？", session_id=session.id)

print(f"Agent: {response2}")


预期输出：

Agent: 好的，小明，我已经记住你的名字了。很高兴认识你！

Agent: 你叫小明，对吗？


💡 提示：第一次运行可能需要安装 honcho 插件。按照提示运行 pip install honcho 即可。



1.4 Hermes Agent 的项目结构



了解项目结构能帮助你更好地理解代码。克隆或下载 hermes-agent 源码后，你会看到这样的目录：

hermes-agent/

├── agent/                    # Agent 核心代码

│   ├── __init__.py

│   ├── run_agent.py        # Agent 主循环入口

│   ├── prompt_builder.py   # 提示词构建

│   └── ...

├── plugins/                 # 插件目录

│   └── memory/              # 记忆插件

│       ├── builtin/        # 内置记忆

│       └── honcho/         # Honcho 记忆插件

├── skills/                  # Skill 定义目录

│   ├── dogfood/            # 狗粮分析 Skill

│   ├── creative/           # 创意写作 Skill

│   └── apple/              # Apple 相关 Skill

├── acp_adapter/            # ACP 协议适配器

│   └── server.py

├── run.py                  # 启动脚本

├── pyproject.toml          # 项目配置

└── README.md


关键目录说明：

目录作用

agent/Agent 的核心逻辑，包括主循环、提示词构建等
plugins/memory/记忆系统的插件，有多种实现可选
skills/Skill 定义文件，描述 Agent 的各种技能
acp_adapter/多 Agent 协作的通信适配器



1.5 Hermes Agent vs 其他框架



你可能听说过其他 Agent 框架，比如 LangChain、AutoGPT、CrewAI。简单对比一下：

框架特点适合场景

Hermes Agent内置学习循环、Skill 机制、ACP 协议需要多 Agent 协作、长期记忆的应用
LangChain生态庞大、组件丰富快速原型、灵活组合各种组件
CrewAI多 Agent 协作友好团队协作场景（角色扮演、任务分配）
AutoGPT自主规划能力强完全自动化的复杂任务

Hermes Agent 的独特优势：

  • Skill 机制：通过写 Markdown 文件就能扩展 Agent 能力门槛低
  • ACP 协议：标准化多 Agent 通信，集成其他 Agent 系统
  • 插件化 Memory：记忆系统可替换，适应不同场景需求




1.6 异步编程预告



Hermes Agent 使用了 异步编程（Async/Await）来提高效率。不用担心，你不需要成为异步专家才能用它。

简单理解：

同步：你排队买咖啡，必须等前一个人买完才能轮到你。


>

异步：你下单后可以去干别的事，咖啡好了服务员叫你。



如果你想深入理解，第 2 章会详细讲解 Hermes Agent 如何用异步编程构建主循环。



⭐ 重点回顾



  • Agent = AI 模型 + 工具 + 记忆 + 规划循环，能"动手做事"
  • Hermes Agent 是支持多 Agent 协作、内置学习循环的开源框架
  • 运行 Agent 的最小代码只需要 4 行
  • Hermes Agent 的核心模块：agent/、plugins/memory/、skills/、acp_adapter/
  • Skill 机制、ACP 协议、插件化 Memory 是 Hermes 的独特优势
